# Projetos de Mapas com Flutter

Repositório com três atividades desenvolvidas em Flutter envolvendo mapas, localização e rotas.
[Tutorial](https://github.com/wellifabio/senai2026/tree/main/ds/turmas/2DES_B/4%C2%BA%20Semestre/03-ppdm2/aula05)

---

## 1. Google Maps

Aplicativo que utiliza o **Google Maps** para exibir um mapa e obter a latitude e longitude ao clicar em um ponto.

### Atividade

* Criar o projeto do tutorial
* Testar no **emulador**
* Tirar print do aplicativo funcionando
* Criar um ícone para o aplicativo
* Gerar o arquivo APK
* Copiar o APK para a pasta `assets/`

---

## 2. Flutter Map

Aplicativo que utiliza o **Flutter Map**, uma alternativa gratuita e Open Source para trabalhar com mapas, funcionando também no navegador.

O aplicativo permite visualizar o mapa e obter a latitude e longitude ao clicar em um ponto.

### Atividade

* Criar o projeto do tutorial
* Testar o aplicativo
* Tirar print
* Criar um ícone para o aplicativo
* Gerar o arquivo APK
* Copiar o APK para a pasta `assets/`

---

## 3. Traçar Rotas com Google Maps e OSRM

Aplicativo desenvolvido para **traçar uma rota entre dois pontos no mapa**, utilizando o Google Maps e a API **OSRM** para calcular a rota.

### Atividade

* Criar o projeto do tutorial
* Utilizar a API OSRM para obter a rota
* Testar o aplicativo
* Tirar print
* Criar um ícone para o aplicativo
* Gerar o arquivo APK
* Copiar o APK para a pasta `assets/`

---
